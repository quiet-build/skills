# plugin.json

Registers the skill folders shipped by the quiet-build-skills plugin. Version 0.5.0 adds the stack skills web-stack, game-stack, and macos-stack.

When adding or removing a skill, update the `skills` paths and README catalog together. Each registered folder must contain a valid SKILL.md. Bump the plugin version for published changes; keep paths relative to the repository root. The manifest registers a plugin, not a separate marketplace.
